## 详细映射

### #1 商品/房源卡片（Listing Card）

**Airbnb 原组件**
- 上方主图（默认 16:10 比例）+ 右上角心形收藏
- 中间标题 + 地点
- 下方：评分 ⭐ + 评价数 / 价格 + 起始词"$/night"

**本项目应用**
- 商城小程序：首页推荐位、分类页商品列表、商品列表页卡片、详情页底部推荐
- 数量：估算 100+ 张卡片实例

**改动**
| Airbnb | 本项目 | 说明 |
|---|---|---|
| 16:10 主图 | 4:5 主图 | 电商商品图传统比例更近正方/长方 |
| 心形收藏 | 移除（M2 引入）| MVP 不做收藏 |
| 标题 + 地点 | 标题（≤ 2 行省略）| 商品名常更长 |
| 评分 + 评价 | 销量（"销量 N")| 电商更看销量信号 |
| 价格 + "/night" | `¥` + 价格红色加粗 | 中文 + 红色高凸显价格 |
| 无促销标 | 加可选红色 Tag | 大促/折扣信息 |

**为什么改**
电商场景下用户决策因素 = 价格 + 销量（销量代表信任）。房源场景下评分代表信任，与电商不重合。比例与字段必须迁移。

### #2 详情页布局（Listing Detail Page）

**Airbnb 原组件**
- 顶部：图片轮播（5+ 张，可滑动）
- 中段左：标题 / 评分 / 简介 / 房东信息 / 设施列表 / 评价
- 中段右（桌面端）/ 下段（移动端）：固定预订卡（日期选择 + 客人数 + "Reserve" 按钮）

**本项目应用**
- 商城小程序：商品详情页（唯一）

**改动**
| Airbnb | 本项目 | 说明 |
|---|---|---|
| 图片轮播 5+ 张 | 主图 ≥ 3 张 + 可选视频 | PIM 维护，数量灵活 |
| 房东信息 | 品牌信息（可选 logo）| 电商品牌即"卖家"|
| 设施列表 | 商品参数 / 卖点 | 不同场景的关键信息 |
| 评价区 | 推荐位（关联商品）| M1 不做评价；推荐促进相邻购买 |
| 预订卡：日期 + 客人数 | SKU 选择区：规格按钮组 + 数量步进器 | 电商核心是选规格不是选日期 |
| 桌面端固定右侧 | 小程序仅底部固定行动条（加购 + 立即购买）| 移动单列布局 |
| "Reserve" 按钮 | "加入购物车" + "立即购买"双按钮 | 电商二段决策路径 |

**为什么改**
预订房与购买商品的核心动作截然不同：前者选日期/人数即可下单；后者必须先选规格、再决定加购 vs 直接买。底部固定行动条照搬 Airbnb（手机版），按钮内容重写。

### #3 筛选器（Filters）

**Airbnb 原组件**
- 顶部一排 chips（房源类型 / 价格 / 设施快捷过滤）
- 右上角"All filters"按钮打开侧滑/全屏详细筛选面板（价格区间双滑块、卧室数、特色等）
- 底部"显示 N 处住所"提交按钮

**本项目应用**
- 商城小程序：商品列表页

**改动**
| Airbnb | 本项目 | 说明 |
|---|---|---|
| 顶部 chips：房源类型 | 顶部排序 chips：综合 / 销量 / 价格升 / 价格降 / 上新 | 电商首层导航 = 排序 |
| All filters 按钮 | "筛选"按钮（右上角漏斗 icon）| 同等功能 |
| 详细筛选：价格 / 卧室 / 设施 | 详细筛选：价格区间 / 品牌（多选）/ 销售属性（多选）| 电商关注品牌与属性 |
| "显示 N 处住所" | "显示 N 件商品" | 直接照搬命名规则 |
| 重置按钮 | 同 | 一致 |

**为什么改**
- 排序 chips 替代房源类型 chips：电商一级筛选行为更多是"按什么排"
- 维度替换：电商核心维度 = 价格 + 品牌 + 属性；房源维度（卧室数等）不适用

### #4 顶部导航 + 搜索栏（Header & Search Bar）

**Airbnb 原组件**
- 桌面：左 Logo + 中间圆角搜索框（"位置 / 日期 / 客人"三段组合）+ 右侧用户菜单 / 列出房源
- 移动：简化为顶部搜索 chip

**本项目应用**
- 商城小程序：首页顶部固定栏

**改动**
| Airbnb | 本项目 | 说明 |
|---|---|---|
| 三段搜索（位置/日期/客人）| 单段商品搜索 placeholder "搜索商品" | 电商搜索单维度 |
| 用户菜单 | 登录入口（未登录显"登录"，已登录显头像）| MVP 不做完整菜单 |
| 列出房源入口 | 移除 | 不涉及商家端入口 |
| 无购物车 | **新增购物车 icon + 数量角标** | 电商必备 |

**为什么改**
- 搜索从多段简化到单段：电商搜索没有日期等结构化条件
- 加购物车角标：用户对购物车数量极敏感，必须实时可见

---

### #5 Tab 切换（Trip Tabs）

**Airbnb 原组件**
- 行程列表 Tabs：Upcoming / Past / Cancelled
- 选中文字加粗 + 下划线
- 切换有平滑动画

**本项目应用**
- 商城小程序：订单列表页（全部 / 待付款 / 待发货 / 待收货 / 已完成）

**改动**
| Airbnb | 本项目 | 说明 |
|---|---|---|
| 3 个 tab | 5 个 tab | 电商订单状态多 |
| 无角标 | **2 个 tab 加数量角标**（待付款/待收货）| 提醒用户有未完成订单 |
| 文字 + 下划线 | 同 | 完全照搬 |
| 切换动画 250ms | 同 | 完全照搬 |

**为什么改**
- Tab 数量从 3 增至 5：贴合电商订单生命周期
- 角标为新增：电商订单有"待操作"语义，必须可视化

## 不复用的 Airbnb 组件（明确说明）

| Airbnb 组件 | 不复用原因 |
|---|---|
| 日历组件（CheckIn/CheckOut Picker）| 电商无入住日期概念 |
| 地图（Map View）| 商品列表不需地理可视化 |
| 评价区（Reviews）| MVP 不做评价 |
| 房东资料（Host Profile）| 商城不强调单一卖家 |
| 国际化语言切换 | MVP 仅中文 |

## 后台不复用 Airbnb 的说明
Airbnb 几乎无中后台界面公开。商家后台基于 Element Plus 标准组件库自行设计：
- 表格：el-table
- 表单：el-form
- 导航：el-menu 左侧 + 顶部面包屑
- 弹窗：el-dialog
- 主题色覆盖为 `#FF385C`（同小程序）保持品牌一致

## 实施约束（给开发 Agent）

- 所有"复用"指**视觉与交互一致**，不是直接拷贝 Airbnb 代码
- 小程序使用原生 wxml/wxss 实现，不引入 Airbnb 同款 npm 包
- 后台使用 Element Plus，通过 SCSS 主题覆盖达到品牌色一致
- 每个组件实现完成后由测试 Agent 用 `web-design-guidelines` skill 审核（仅适用于后台 Web）
