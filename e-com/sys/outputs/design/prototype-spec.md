# prototype-spec.md · 原型规范（文本版）

## 【当前焦点】
13 个 MVP 核心页面（小程序 11 + 后台 2）的布局规范 + 状态枚举 + 交互说明。
**本环境无法生成位图原型**，本规范以 markdown 形式描述每个页面的布局、组件、状态、交互，可直接交付给：
- 前端 Agent 在 Phase 1 实现
- 真人设计师转化为 Figma/Sketch 位图
- HTML 原型工具（如 prototype-html skill）生成可点击 demo

## 本任务匹配到的 skill 清单
- `web-design-guidelines`

## 通用约定
- 所有 token 引用见 [design-system.md](design-system.md)
- 所有 Airbnb 组件复用见 [airbnb-components-map.md](airbnb-components-map.md)
- 所有页面必备 4 态：**默认 / 加载 / 空 / 错**（部分页面有额外状态）

## 1. 登录注册页 `/pages/login/index`

### 布局（默认态）
```
┌─────────────────────────┐
│   [<返回]    电商商城    │  ← 顶部栏 44sp，标题居中
├─────────────────────────┤
│                         │
│       [Logo]            │  ← 居中，120×120
│                         │
│   手机号登录 / 注册      │  ← 标题 18sp semibold
│                         │
│  ┌───────────────────┐  │
│  │ 请输入手机号       │  │  ← 输入框 44sp，圆角 4
│  └───────────────────┘  │
│                         │
│  ┌──────────┐ ┌──────┐  │
│  │ 验证码    │ │获取  │  │  ← 验证码 + 获取按钮
│  └──────────┘ └──────┘  │
│                         │
│  ┌───────────────────┐  │
│  │     登录 / 注册    │  │  ← 主按钮 #FF385C
│  └───────────────────┘  │
│                         │
│  ☑ 已阅读《用户协议》   │  ← 默认勾选
│     《隐私政策》         │
└─────────────────────────┘
```

### 状态
| 状态 | 触发 | 表现 |
|---|---|---|
| 默认 | 进入页面 | 上图所示，输入框为空，"获取验证码"按钮置灰 |
| 手机号合法 | 输入完整手机号 | "获取验证码"按钮变主色可点击 |
| 验证码已发 | 点"获取验证码"后 | 按钮变"60s 后重发"灰色倒计时 |
| 验证码冷却中 | 60s 内 | 按钮倒计时 + 不可点 |
| 提交中 | 点登录后 | 主按钮显示 spinner + "登录中"，禁止点击 |
| 错误：手机号格式 | 失焦校验失败 | 输入框下显红字"手机号格式错误"，边框变红 |
| 错误：验证码错 | 后端返回 | 验证码框下显红字"验证码错误" + Toast |
| 错误：账号锁定 | 5 次错误 | Toast"账号已锁定 10 分钟" + 主按钮置灰 |
| 协议未勾选 | 取消勾选 | 主按钮置灰，点击 Toast"请先阅读协议" |

### 交互
- 手机号输入失焦校验
- 60s 倒计时（前端管理，不依赖后端）
- 协议链接打开 webview 嵌入文本
- 登录成功后 `wx.navigateBack()` 到原页面，或 `wx.switchTab` 到首页

| 状态 | 表现 |
|---|---|
| 默认 | 上图，按钮主色可点 |
| 加载 | 顶部图片占位 + 下方骨架屏 |
| SKU 不可选 | 该属性按钮置灰 + "无此组合" tooltip |
| 库存 ≤ 5 | "仅剩 N 件"红字 |
| 库存 = 0 | 按钮变"无货" 灰色不可点 |

- 数量步进器（min 1, max min(库存, 99)）
- 加购成功 Toast "已加入购物车" + 购物车角标 +1
- 立即购买跳结算页带当前 SKU + 数量
