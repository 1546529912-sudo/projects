# edge-cases.md · 边界与异常情况清单

## 【当前焦点】
列出 4 个系统 MVP 范围内的边界、异常、并发、容错场景。供开发 Agent 在实现 task-spec 时直接对照。
**所有边界场景必须在 task-spec 的对应任务中体现为判定项。**

## 本任务匹配到的 skill 清单
- `prd-development` / `user-story-splitting` / `epic-breakdown-advisor`

## 一、跨系统通用边界

| 编号 | 场景 | 期望行为 |
|---|---|---|
| GEN-01 | 跨系统接口调用幂等性 | 同一 `Idempotency-Key` 重复请求返回首次结果，不重复创建数据 |
| GEN-02 | 跨系统接口超时 | 调用方设置超时 ≤ 3s；超时后返回明确错误码 + 不留半成品数据 |
| GEN-03 | Redis Stream 消费失败 | 最多重试 3 次；失败入死信队列 + 日志告警 |
| GEN-04 | MySQL 连接超限 | 连接池满 → 排队 ≤ 500ms → 仍失败返回 503 |
| GEN-05 | 时间戳一致性 | 4 系统统一使用服务器 UTC 时间，DB 字段 datetime 默认 CURRENT_TIMESTAMP |
| GEN-06 | 金额精度 | 所有金额以"分"为单位的 int 存储，避免 float 精度丢失 |
| GEN-07 | 手机号脱敏 | 列表展示脱敏（138****1234），详情可点击解密（需权限）|
| GEN-08 | 字符串长度边界 | 商品名 ≤ 100、描述 ≤ 2000、备注 ≤ 500，超长截断或拒绝并提示 |

## 二、商城系统边界

### 用户/登录
| 编号 | 场景 | 期望行为 |
|---|---|---|
| SHOP-E01 | 手机号格式错误 | 客户端实时校验（^1[3-9]\d{9}$），提交时再校验 |
| SHOP-E02 | 验证码 60s 冷却内重发 | 按钮置灰显示倒计时 |
| SHOP-E03 | 验证码超 5 分钟仍提交 | 返回"验证码已过期"，引导重新获取 |
| SHOP-E04 | 验证码错误连续 5 次 | 锁定该手机号 10 分钟（写入 Redis） |
| SHOP-E05 | 未登录访问加购/下单 | 弹登录浮层，登录后回到原页面与原操作 |

### 商品详情/SKU
| 编号 | 场景 | 期望行为 |
|---|---|---|
| SHOP-E10 | 商品已下架（PIM 状态） | 整页可看不可下单，按钮置灰显示"已下架" |
| SHOP-E11 | SKU 组合不存在 | 该属性按钮置灰，不可选 |
| SHOP-E12 | 选中 SKU 库存=0 | 按钮显示"无货"，禁止加购 |
| SHOP-E13 | 切换 SKU 后价格/图片/库存联动 | 100ms 内 UI 更新，无闪烁 |
| SHOP-E14 | 商品被删除（PIM 下架并清理） | 详情页 404 + 引导回首页 |

### 购物车
| 编号 | 场景 | 期望行为 |
|---|---|---|
| SHOP-E20 | 购物车 SKU 已下架 | 移入"失效区"，不参与结算 |
| SHOP-E21 | 购物车 SKU 库存不足 | 数量上限锁定到当前库存，提示"仅剩 N 件" |
| SHOP-E22 | 同一 SKU 重复加购 | 数量累加而非新建条目 |
| SHOP-E23 | 跨设备购物车同步 | 登录后云端覆盖本地，本地未登录购物车合并入云端 |
| SHOP-E24 | 单 SKU 数量超过 99 | 步进器锁定 99，提示"单次购买不超过 99" |

### 结算/支付
| 编号 | 场景 | 期望行为 |
|---|---|---|
| SHOP-E30 | 结算时库存或价格变化 | 提示"商品信息已变更"，刷新页面后再结算 |
| SHOP-E31 | 提交订单 → OMS 锁库存失败 | 返回明确错误（库存不足/SKU 已下架），不创建订单 |
| SHOP-E32 | 支付倒计时到 30 分钟仍未付 | 订单自动取消，释放锁定库存 |
| SHOP-E33 | 微信支付 SDK 拉起失败 | 提示"支付环境异常"，可重试 |
| SHOP-E34 | 支付成功但回调延迟 | 支付结果页轮询 OMS 状态，最多 3 次，每次 5s |
| SHOP-E35 | 重复提交订单（双击）| 前端按钮防抖 500ms；后端按 Idempotency-Key 去重 |

### 订单
| 编号 | 场景 | 期望行为 |
|---|---|---|
| SHOP-E40 | 订单列表空态 | 显示"暂无订单" + 引导按钮 |
| SHOP-E41 | OMS 接口超时 | 显示"加载失败，点击重试" |
| SHOP-E42 | 状态变更（如已发货）|订单详情进度条实时更新（轮询或事件推送）|

## 三、PIM 系统边界

| 编号 | 场景 | 期望行为 |
|---|---|---|
| PIM-E01 | 类目编码重复 | 提交时返回"编码已存在" |
| PIM-E02 | 父类目禁用而子类目有在售商品 | 阻止禁用，提示影响的商品数 |
| PIM-E03 | 类目层级超 5 级 | 新建时第 6 级按钮置灰 |
| PIM-E04 | 删除类目时存在 SPU | 阻止删除，提示"请先迁移商品" |
| PIM-E05 | 属性被 SPU 使用 | 不可删除，只能禁用 |
| PIM-E06 | 属性模板调整 | 提示影响的商品数，二次确认 |
| PIM-E07 | SPU 删除时有 SKU 关联订单 | 阻止删除，提示"存在进行中订单" |
| PIM-E08 | SKU 编码重复 | 提交时拒绝 |
| PIM-E09 | 单 SPU 下 SKU > 500 | 阻止创建，提示上限 |
| PIM-E10 | 销售属性变更 | 重新生成 SKU 列表，已有 SKU 价格保留 |
| PIM-E11 | 图片上传超 5MB | 客户端校验拒绝 + 服务端二次校验 |
| PIM-E12 | 富文本中嵌入恶意 script | 后端用白名单 HTML 过滤（如 HTMLPurifier） |
| PIM-E13 | 品牌被使用后禁用 | 已绑商品照常展示，新建商品该品牌不可选 |
| PIM-E14 | 商品状态变更事件 | Redis Stream 推送，下游订阅 ≤ 5s 收到 |

## 四、OMS 系统边界

### 订单接收
| 编号 | 场景 | 期望行为 |
|---|---|---|
| OMS-E01 | 重复订单（同 Idempotency-Key）| 返回首次结果，不创建新订单 |
| OMS-E02 | 商品 SKU 在 PIM 已不存在 | 拒绝订单，返回"商品已下架" |
| OMS-E03 | 收货地址不完整 | 字段校验失败，返回字段名 + 原因 |
| OMS-E04 | 订单总金额计算不一致（商城 vs OMS）| 以 OMS 计算为准，返回不一致提示，由商城重新提交 |

### 库存四态
| 编号 | 场景 | 期望行为 |
|---|---|---|
| OMS-E10 | 高并发同 SKU 下单（200+ 并发）| 用 Redis 分布式锁（按 SKU）+ MySQL 行锁双重保护，不超卖 |
| OMS-E11 | 锁定库存后订单取消 | 释放锁定 + 写流水（change_type=unlock） |
| OMS-E12 | 支付超时自动取消 | 定时任务每 5 分钟扫描，超 30 分钟未支付的订单自动取消 |
| OMS-E13 | 可用库存 = 实物 - 锁定 - 预留 | 任何变动后实时重算，对外推送 |
| OMS-E14 | 大促缓冲（本期默认 0） | 配置项预留，对外可用库存 = 计算值 - 缓冲值 |

### 状态机
| 编号 | 场景 | 期望行为 |
|---|---|---|
| OMS-E20 | 非法状态跳转（如待支付→已出库）| 拒绝并记录日志 |
| OMS-E21 | WMS 出库回传重复 | 幂等处理，状态机只迁移一次 |
| OMS-E22 | WMS 短拣回传 | 订单状态→异常，推商家后台处理（M1 暂只记录） |

### WMS 对接
| 编号 | 场景 | 期望行为 |
|---|---|---|
| OMS-E30 | WMS 拣货单下发失败 | 重试 3 次 + 入死信队列 + 告警 |
| OMS-E31 | WMS 出库回传迟于 OMS 状态查询 | 商城查询返回"备货中"，等回传到达后再变"已出库" |

## 五、WMS 系统边界

### 基础数据
| 编号 | 场景 | 期望行为 |
|---|---|---|
| WMS-E01 | SKU 编码重复 | 拒绝创建 |
| WMS-E02 | 库位编码非法（不符合"区域-货架-层"）| 拒绝创建 |
| WMS-E03 | 删除有库存的库位 | 阻止，提示"该库位有 N 件 X SKU" |
| WMS-E04 | 库位禁用而有锁定库存 | 允许禁用但提示影响订单数 |

### 入库
| 编号 | 场景 | 期望行为 |
|---|---|---|
| WMS-E10 | 收货实数 > 预收数 | 弹红色提示"超 N 件，是否继续"，需主管审批 |
| WMS-E11 | 收货实数 < 预收数 | 生成差异报告 → 推送主管审批 |
| WMS-E12 | 扫到非本单 SKU | PDA 提示"非本单商品，是否新增" |
| WMS-E13 | 上架库位承重超限 | 拒绝并显示"该库位最大可放 N 件" |
| WMS-E14 | 推荐 Top3 库位都不可用 | 显示降级推荐列表 |

### 库存
| 编号 | 场景 | 期望行为 |
|---|---|---|
| WMS-E20 | inventory 四元组主键冲突 | 数据库强制约束，应用层 UPSERT |
| WMS-E21 | 流水写入失败而库存已变 | 事务回滚，库存不更新 |
| WMS-E22 | 移库目标库位不存在或禁用 | 拒绝操作 |
| WMS-E23 | 同 SKU 并发锁定 200+ 单 | 分布式锁 + 行锁，不超卖 |

### 出库
| 编号 | 场景 | 期望行为 |
|---|---|---|
| WMS-E30 | OMS 推订单时该 SKU 无库存 | 订单状态=缺货，挂起 + 通知主管 |
| WMS-E31 | 拣货时短拣（同 SKU 其他库位有货）| 系统自动生成补拣任务 |
| WMS-E32 | 拣货时短拣（无任何库位有货）| 任务挂起，推送主管 4 选 1 |
| WMS-E33 | 复核扫错商品 | 声光提示 + 不允许结束 |
| WMS-E34 | 快递面单 API 调用失败 | 重试 3 次 + 允许人工补录单号 |
| WMS-E35 | 出库扫码后回传 OMS 失败 | 重试 3 次 + 入死信队列，库存已扣减但状态待同步 |
| WMS-E36 | 快递取件扫码扫了非本单 | 拒绝 + 提示"非本仓出库单" |

### PDA 与权限
| 编号 | 场景 | 期望行为 |
|---|---|---|
| WMS-E40 | PDA 网络断开 | M1 暂不支持离线，提示"请连接网络" |
| WMS-E41 | 角色无权限访问页面 | 跳 403 页面 + 引导回首页 |
| WMS-E42 | PDA 扫错条码 | "嘟"提示音 + 不进入下一步 |

## 六、安全与合规

| 编号 | 场景 | 期望行为 |
|---|---|---|
| SEC-01 | SQL 注入尝试 | ThinkPHP 使用参数化查询；输入过滤 |
| SEC-02 | XSS 富文本攻击 | HTMLPurifier 过滤 |
| SEC-03 | CSRF 攻击 | 后台接口加 CSRF token；API 走签名 |
| SEC-04 | 接口被刷（验证码、登录）| 按 IP + 手机号 限流 |
| SEC-05 | 敏感字段（手机号、地址）日志输出 | 强制脱敏，禁止明文日志 |
| SEC-06 | 上传图片为可执行文件 | MIME 类型 + 文件头双校验，存储后改扩展名 |
