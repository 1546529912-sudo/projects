# feature-breakdown.md · 功能拆解（按系统分章节）

## 【当前焦点】
基于 4 份 PRD 与 [整体架构文档](../../../电商系统整体架构.md)，按系统拆解 MVP 与非 MVP 功能。
**MVP 范围按 prompt §0.4 与 §附录 A 固化**，下面 *斜体* 项为非 MVP（M2-M5/二三期），只列名不展开。

## 本任务匹配到的 skill 清单
- `prd-development`（PRD 结构化细化方法）
- `user-story`（功能 → 用户故事映射）
- `user-story-splitting`（大功能拆小）
- `epic-breakdown-advisor`（epic → 子功能拆分）
- `jobs-to-be-done`（每个功能的用户 Job 定位）
- `problem-statement`（功能背后的问题陈述）

## 一、商城系统（shop）

### MVP（M1：用户侧购物闭环）

| 子功能编号 | 子功能名 | 来源 PRD 章节 | 概述 |
|---|---|---|---|
| SHOP-F1 | 登录注册 | 商城-PRD §5.1, §4.2 | 手机号 + 短信验证码登录/注册（不做密码登录与微信授权 - 推迟到 M2） |
| SHOP-F2 | 首页 | 商城-PRD §5.2 | Banner + 分类导航 + 推荐位 + 热销/新品（首屏 TTI ≤ 2s） |
| SHOP-F3 | 商品分类页 | 商城-PRD §5.3 | 一/二/三级类目浏览，类目数据来自 PIM |
| SHOP-F4 | 商品列表页 | 商城-PRD §5.4 | 筛选（价格/品牌/属性）+ 排序（综合/销量/价格/上新）+ 空态 |
| SHOP-F5 | 商品详情页 | 商城-PRD §5.6 | 主图轮播 + SKU 选择 + 库存联动 + 加购/立即购买 |
| SHOP-F6 | 购物车 | 商城-PRD §5.7 | 选商品/规格、改数量、删除、失效区、合计、跨设备同步（登录用户） |
| SHOP-F7 | 结算页 | 商城-PRD §5.8 | 地址 + 商品清单 + 优惠（M1 仅展示）+ 配送 + 提交订单 |
| SHOP-F8 | 支付页 + 微信支付拉起 | 商城-PRD §5.9 | 倒计时 + 金额展示 + 拉起微信支付 SDK（占位 AppID） |
| SHOP-F9 | 支付结果页 | 商城-PRD §5.10 | 成功/失败/处理中三态 + 轮询 |
| SHOP-F10 | 订单列表页 | 商城-PRD §5.11 | Tab 分类 + 状态对应操作按钮 |
| SHOP-F11 | 订单详情页 | 商城-PRD §5.12 | 状态进度 + 商品/费用明细 + 物流入口 |

### 非 MVP（M2-M5）

- *个人中心 / 收货地址管理 / 优惠券 / 账号设置（M2-M3）*
- *物流跟踪页（M3）*
- *售后申请 / 售后详情 / 商家后台售后管理（M3）*
- *商家后台：登录 / 数据看板 / 商品管理 / 订单管理（M2）*
- *促销：优惠券 / 满减 / 限时秒杀（M4）*
- *用户管理 / 内容管理 / 物流管理 / 权限管理 / 数据统计（M5）*

## 三、OMS 系统

### MVP（M1：接单 + 状态机 + WMS 对接）

| 子功能编号 | 子功能名 | 来源 PRD 章节 | 概述 |
|---|---|---|---|
| OMS-F1 | 订单接收与标准化 | OMS-PRD §5.1 | 接收商城 POST /order；字段校验；幂等去重；落库标准订单（ORD-01, ORD-02, ORD-03, ORD-04） |
| OMS-F2 | 订单状态机 | OMS-PRD §5.4 | 待支付/已支付/备货中/异常/已出库/配送中/已完成；状态变更留痕 |
| OMS-F3 | 库存四态管理 | OMS-PRD §5.5 | 实物/锁定/预留/可用；下单锁定；取消释放；出库扣减（INV-01, INV-02, INV-05） |
| OMS-F4 | 单据管理与 WMS 联动 | OMS-PRD §5.7 §5.8 | OMS→WMS 拣货单下发；WMS→OMS 出库回传消费（DOC-01~05, ROU 简化版） |
| OMS-F5 | 可用库存查询 API | OMS-PRD §5.5 + 整体架构 §8.2 | 商城 GET /inventory/{sku} 实时查询；P95 < 100ms |

### 非 MVP（M2-M5）

- *路由决策引擎 / 多仓多物流（M2）*
- *拆单管理 / 母子单关联（M3）*
- *售后全链路（退货退款/仅退款/换货）（M4）*
- *风控拦截 / 大额订单审核（M2）*
- *规则配置后台 / 大促规则切换（M3）*
- *消息通知 / 短信 / 平台回传（M4）*
- *支付/ERP 对接（M4）*
- *多渠道接单（天猫/京东/抖音）（M4）*
- *库存安全阈值与大促缓冲（M2，本期保留配置项默认 0）*

## 四、WMS 系统

### MVP（一期：入库 → 库存 → 出库最小闭环）

| 子功能编号 | 子功能名 | 来源 PRD 章节 | 概述 |
|---|---|---|---|
| WMS-F1 | 基础数据：SKU/仓库/库位 | WMS-PRD §6.1 | SKU CRUD（含 weight/safety_stock）+ 仓库 CRUD + 库位 CRUD（区域-货架-层格式） |
| WMS-F2 | 入库单 + 收货 + 上架 | WMS-PRD §6.2 + US-03/04/05 | 入库单创建 + PDA 扫码收货 + 库位推荐 Top3 + 上架（拆分多库位） |
| WMS-F3 | 库存表 + 库存流水 | WMS-PRD §6.3 | inventory 表（四元组唯一）+ inventory_log（append-only）+ 移库 |
| WMS-F4 | 出库（摘果式）+ 复核 + 出库扫码 | WMS-PRD §6.4 + US-08/09/10/11/12 | 接 OMS 拣货单 → FIFO 锁库存 → PDA 摘果式拣货 → 复核 → 快递面单 → 出库扣实物 → 回传 OMS |
| WMS-F5 | RBAC 角色与权限 | WMS-PRD §7.5 + US-13 | 6 个预置角色（管理员/主管/收货/拣货/复核/运营）+ 菜单数据权限 |

### 非 MVP（二三期）

- *波次拣货 / 播种式（二期）*
- *盘点（全盘/区域/抽盘/异动盘）（二期）*
- *退货管理与质检分流（二期）*
- *批次管理 / 保质期 / ABC 分类（二期）*
- *8 类核心报表 + 预警（二期）*
- *库存预警 / 多仓调拨 / 补货建议（三期）*
- *PDA 离线模式（二期，本期假设网络在线）*
- *黄金库位推荐策略（二期）*
