## 三、目标用户审美定位

### 3.1 用户侧（小程序）
- **目标人群**：C 端年轻消费者（18-35 岁，城市，月可支配 ≥ 2000 元）
- **审美预期**：克制、留白多、信息密度低、强调商品图片质感
- **类比标杆**：Airbnb / 淘宝 iOS / 小红书购物
- **必须避免**：拼多多式信息爆炸、密集小字、动态闪烁广告、土味金红配色

### 3.2 商家后台（Vue + Element Plus）
- **目标人群**：商家运营/客服/财务（25-45 岁，电脑使用熟练）
- **审美预期**：信息密度中等、表格为主、操作可见、状态清晰
- **类比标杆**：Element Plus 官方示例 / 阿里中后台规范
- **必须避免**：用户侧的留白风格（后台单屏需展示更多数据）

## 六、每个页面必须设计的状态枚举

设计 Agent **不允许只画默认态**。每个页面至少画：

| 状态 | 触发 | 设计要求 |
|---|---|---|
| 默认态 | 正常加载完成 | 主要交付物 |
| 加载态 | 数据请求中 | 骨架屏（避免转圈）|
| 空态 | 数据为空 | 图标 + 文案 + 引导按钮 |
| 错误态 | 接口异常 / 网络断 | 错误码 + 重试按钮 |

部分页面额外状态：
- **商品详情页**：商品已下架、SKU 无货、库存 ≤ 5 件（紧迫感提示）
- **购物车**：空购物车 vs 有失效商品
- **结算**：地址未选 vs 库存变化中断
- **支付**：倒计时还剩 < 5 分钟（视觉强调）

## 七、必须设计的交互细节

| 细节 | 期望 |
|---|---|
| 按钮点击反馈 | 0.2s 缩放 + 颜色变深 |
| 加载动画 | 骨架屏 > loading 转圈 |
| Toast 提示 | 顶部居中，2s 自动消失 |
| 二次确认 | 删除/退款用底部抽屉确认 |
| 表单错误 | 字段下方红色文字 + 边框变红 |
| 长列表 | 无限滚动 + 触底加载更多 |
