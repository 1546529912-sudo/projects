### 项目规模判断

本项目属于 DESIGN.md 定义的 **中型集合**（SaaS/有外部依赖）：
- 有独立的 AI 微服务（Python）
- 有第三方支付接入
- 有文件存储外部依赖
- 未来需对接 CRM 和仓储管理

架构 Agent 需输出 6 份文档：tech-stack / data-schema / api-list / module-deps / data-flow / non-functional。

### 关键架构决策

1. **PHP + Python 双语言架构**：PHP Laravel 负责所有业务逻辑（用户/商品/订单/支付），Python FastAPI 负责 AI 能力（RAG/意图识别/报价计算），两者通过内网 HTTP API 通信
2. **AI 服务接口约定**：PHP 发送 JSON 请求到 Python 服务，Python 返回结构化 JSON（报价单/客服回答/意图分类），PHP 不直接调用模型
3. **数据库统一**：MySQL 存储所有业务数据，AI 对话记录也写入 MySQL，向量数据库仅存储 RAG embedding

### TRADE-001-01 手机号+验证码注册

**一句话描述：** 用户通过手机号和短信验证码完成个人账号注册。

| # | 判定项 | 验证方式 |
|---|--------|---------|
| 1 | 输入合法手机号点击发送验证码，60秒内收到6位数字短信 | 测试环境用mock短信服务，检查sms_logs表记录 |
| 2 | 验证码60秒倒计时期间，发送按钮置灰不可点击，倒计时结束恢复 | UI自动化：检查按钮disabled属性+倒计时文字 |
| 3 | 输入正确验证码提交后，users表新增一条记录（status=active, phone已填）| 查MySQL users表，断言phone和status字段 |
| 4 | 手机号已注册时，页面提示"该号码已注册"并展示"去登录"链接 | 先注册一个号，再用同号注册，检查提示文案和链接跳转 |
| 5 | 验证码输错3次后，锁定该手机号5分钟不可重新发送，页面提示锁定剩余时间 | 连续3次错误验证码提交，检查第4次发送按钮状态和提示文案 |
| 6 | 验证码超过5分钟过期，提交后提示"验证码已过期，请重新获取" | 等待5分钟或手动修改redis过期时间，提交旧验证码检查提示 |

### AI-001-01 报价入口

# 四、边界与异常清单（edge-cases）

## 用户模块
- 同一手机号同时在两个浏览器注册，第二个提交时应提示"已注册"
- 企业认证被驳回后，用户可重新提交，驳回原因需展示
- 微信登录绑定的手机号与已有账号手机号冲突，需引导合并账号或换号绑定

## 商品模块
- 商品下架后，已在购物车中的该商品标红提示"已下架"，不可结算
- 搜索无结果时展示"未找到匹配商品，建议调整关键词"+ 热搜推荐
- 商品批量导入Excel格式错误时，返回错误行号和原因，成功行正常入库
- 阶梯价设置时数量区间重叠，保存时校验并提示

## 订单模块
- 并发下单导致库存不足：使用Redis预扣库存 + MySQL乐观锁，库存不足时提交订单失败并提示
- 对公转账超72小时未上传凭证，订单自动取消，库存释放
- 用户在"待发货"状态申请取消，需管理员审批，审批期间订单冻结
- 支付回调延迟（微信/支付宝异步通知），订单保持"待付款"直到回调确认，不可重复支付
- 部分发货场景：一个订单含多个SKU，部分先发货，订单状态显示"部分发货"

## AI模块
- AI报价时用户输入完全无关内容（如"今天天气怎么样"），AI应识别为闲聊并引导回报价场景
- AI报价参数全部缺失（用户只说"我要买东西"），AI连续追问最多3轮，仍无法获取关键参数则转人工
- AI对话过程中用户突然关闭页面，再次打开时恢复上次对话
- RAG知识库为空时（初始化阶段），AI回复"暂时无法回答此问题，已为您转接人工客服"
- AI生成的报价单中商品价格与实时价格不一致（价格在AI计算期间被修改），报价单需标注"价格以下单时为准"

## 支付模块
- 在线支付成功但平台未收到回调，需设置定时任务主动查询支付状态
- 对公转账凭证上传后，管理员确认金额与订单金额不符，驳回并通知用户补差或退款
- 用户支付后立即申请退款，退款走原路返回（微信/支付宝），对公转账退款需人工处理
