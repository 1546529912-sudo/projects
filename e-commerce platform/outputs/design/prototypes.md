│   ┌────┐ ┌────┐ ┌────┐ ┌────┐                       │  ← 推荐商品 4 张
│   │ 图 │ │ 图 │ │ 图 │ │ 图 │                       │

│   │型号│ │型号│ │型号│ │型号│                       │

└─────────────────────────────────────────────────────┘
                                              [💬AI]   ← 右下悬浮 AI 入口
```

### 状态枚举

| 状态 | 描述 | 视觉处理 |
|------|------|---------|
| 默认 | 完整内容呈现 | 全色 |
| 加载 | 推荐商品区骨架屏 | shimmer 动画 |
| 完成 | 搜索后跳转列表页 | URL query + 列表 |
| 异常 | 推荐数据接口失败 | "暂无推荐商品" 占位图 + 重试按钮 |

### 交互说明

- 点击 logo → 回到首页（已在首页不刷新）
- 点击分类入口卡片 → 跳转商品列表页 + URL 携带 `category_id`
- 点击商品卡片 → 跳转商品详情页
- 搜索栏回车 / 点击 orb → 跳转列表页 + URL 携带 `keyword`
- 右下 AI 浮按钮 → 打开右侧抽屉对话窗

### 边界标注

- 推荐区为空时不渲染区块，避免"留白尴尬"
- 搜索框输入超 100 字截断
- 用户已登录且未完成企业认证 → header 头像下"企业认证"红点提醒

│         您要 T700 板材，          │

│                                  │

│   ┌─────────────────┐            │
│   │ T700 3MM        │            │

│                                  │

│ [输入框                  ]  [→]   │  ← 底部输入
│ [转人工] [新对话]                 │
└─────────────────────────────────┘
```

### 状态枚举

| 状态 | 视觉 |
|------|------|
| 默认 | 空对话或初始欢迎语 |
| AI 思考中 | "AI 正在输入..." 三点动画 |
| 完成 | 报价单卡片渲染 |
| 异常 LLM 超时 | "AI 暂时繁忙，已为您转接人工" + 联系方式 |
| 异常无匹配 | "未找到匹配商品，建议调整参数" + 转人工按钮 |
| 边界长消息 | 消息气泡最大 80% 宽度，超出换行 |

### 交互说明

- 触发：商品详情页 "AI 报价" / 首页右下浮按钮 / 任意页悬浮按钮
- 关闭抽屉 ≠ 清空对话（重新打开恢复）
- "新对话"按钮 → 二次确认 → 清空当前对话
- "转人工"按钮 → 立即转接 + 后续消息发给人工
- 报价单卡片可点击 → 展开详情 / "立即下单"按钮一键转结算
- 抽屉打开时主页面变暗 10%，背景仍可滚动（不阻挡）

### 边界标注

- 未登录用户先弹登录 → 登录后回到对话
- 上下文超 20 轮自动截断最早消息
- 非工作时间转人工时显示"工作时间 9-18 点，已为您留言"
- 消息超 500 字截断 + 提示"消息过长"

## 通用规范

### 加载占位（骨架屏）

```
┌────────────┐    ┌────┐ ┌────┐
│ ▓▓▓▓▓▓▓▓  │    │▓▓▓▓│ │▓▓▓▓│
│ ▓▓▓▓      │    │    │ │    │
│ ▓▓▓▓▓▓    │    │▓▓  │ │▓▓  │
└────────────┘    └────┘ └────┘
```

- 骨架色 `#f7f7f7`
- 高亮条 shimmer 动画 1.5s 循环
- 至少出现 100ms 才显示（避免闪烁）

### 错误状态

- 文案统一从语义色：错误用 `#c13515`、警告用 `#F39C12`
- 错误页：404 / 500 用插画占位（待美术补充） + "返回首页"按钮
- 接口错误 toast：3 秒消失，右上角

### 空状态

- 占位插画 + 一句文字（≤15 字） + 一个 CTA 按钮
- 不留空白页

### 法务/合规元素

- 注册页"同意服务协议"必勾
- footer 备案号 + 公司信息
- 隐私政策入口必有
