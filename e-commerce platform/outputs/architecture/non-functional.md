# Non-Functional · 非功能需求（架构 Agent 产物 6/6）

> 性能 / 容灾 / 安全 / 可观测 / 合规。中型 SaaS 档位必出。

## 【当前焦点】

- 性能目标：首屏 <2s / AI 首响 <3s / 接口 P99 <500ms
- 安全基线：用户数据加密 + 防注入 + 限流 + 鉴权
- 合规：网安备案 + 等保 2.0（第一期 2 级，第二期视量级评估升级）

## 1. 性能

### 接口性能目标

| 接口类型 | P50 | P99 |
|---------|------|------|
| 商品列表 / 详情 | <100ms | <500ms |
| 购物车 / 价格计算 | <150ms | <500ms |
| 下单 | <300ms | <1000ms |
| 支付发起 | <500ms | <2000ms |
| 物流查询 | <200ms (含 5min 缓存) | <800ms |
| AI 首次响应 | <1s | <3s |
| AI 后续 token 流 | 持续输出 30 tokens/s | - |

### 前端性能目标

| 指标 | 目标 |
|------|------|
| FCP (First Contentful Paint) | <1.5s |
| LCP (Largest Contentful Paint) | <2.5s |
| TTI (Time To Interactive) | <3s |
| CLS (Cumulative Layout Shift) | <0.1 |
| Lighthouse 综合分 | ≥85 |

### 优化策略

- **CDN：** 静态资源 + 商品图片走 CDN
- **HTTP 缓存：** 商品图片 `Cache-Control: max-age=31536000`（永久）
- **接口缓存：** 商品详情 5 分钟 Redis 缓存；首页推荐 1 分钟
- **数据库：** 高频查询字段建索引；分页限制 ≤100；避免 N+1（Eloquent eager loading）
- **图片懒加载：** 列表页非首屏图懒加载
- **代码分割：** Vue 路由级动态 import
- **Element Plus 按需加载：** unplugin-vue-components
- **Gzip / Brotli：** Nginx 启用

### 并发与吞吐

- **预期 QPS：** 100 RPS（第一期 MVP）
- **设计承载：** 单实例 200 RPS（PHP-FPM 50 进程 × 4 实例）
- **数据库连接池：** 100 连接 × 2 实例 = 200 连接
- **Redis 连接池：** 50 连接 × 2 实例

## 2. 容灾与可用性

### SLA 目标

- 系统可用性：99.5%（每月停机 ≤ 3.6 小时）
- 数据库故障切换：≤ 60s（阿里云 RDS 自动主备切换）
- 关键数据备份：每日全量 + 每 5 分钟增量备份（binlog）

### 失效降级策略

| 失效组件 | 降级行为 |
|---------|---------|
| FastAPI AI 服务 | AI 抽屉显示"AI 暂时繁忙"+ 转人工入口 |
| pgvector | 知识库降级返回"暂无信息" + 转人工 |
| LLM 第三方 | 降级到本地 FAQ 关键词匹配 |
| 微信/支付宝 | 切换为对公转账（人工） |
| 物流（快递鸟） | 显示"物流接口暂不可用，请联系客服" |
| 阿里云 OSS | 图片显示占位图 |
| Redis | 关闭购物车价格实时计算（降级到下单时算） |
| MySQL | 不可用，整站维护页 |

### 多机房 / 跨可用区（第二期）

- 第一期：单可用区 + RDS 主备
- 第二期：跨可用区 ALB + 双机房 Redis Sentinel + MySQL 跨机房同步

## 3. 安全

### 鉴权

- 前端走 Bearer Token（Sanctum）；token 7 天有效期；refresh token 30 天
- 后台 admin 走双因素（密码 + 短信验证码登录）
- 接口按角色权限校验（Laravel Gate / Policy）

### 数据保护

| 数据 | 处理 |
|------|------|
| 密码 | bcrypt 哈希（不可逆）|
| 手机号（数据库） | AES-256 加密存储 |
| 手机号（API 返回） | 中间 4 位用 `*` 脱敏：`138****8000` |
| 营业执照 | OSS 私有桶 + 临时签名 URL（10 分钟过期） |
| 支付凭证 | 同上 |
| AI 对话内容 | 明文存储（业务需要复盘）；敏感词过滤 |

### 防注入与攻击

- SQL 注入：Laravel Eloquent 默认参数化查询，禁用 DB::raw 拼接
- XSS：Laravel Blade `{{ }}` 自动 escape；前端 v-html 严格 review
- CSRF：Sanctum cookie + token 双层防护
- 文件上传：白名单后缀 + 内容扫描（OSS 内置）+ 文件大小限制
- 接口限流：见 [api-list.md](api-list.md) 第 10 节
- 验证码暴破：5 次错误锁定 5 分钟（Redis 计数器）
- HTTPS 强制：Nginx 301 重定向 http → https
- HSTS：`max-age=31536000; includeSubDomains; preload`

### 越权防护

- 横向越权：任何用户操作必须校验"资源属于当前用户"（如查订单时 `WHERE user_id = auth_id`）
- 纵向越权：admin 接口严格按角色 middleware 拦截
- AI 查询订单：必须校验订单归属当前登录用户

### 安全审计

- 关键操作记日志：登录 / 支付 / 退款 / 后台修改商品 / 后台修改库存
- 日志保留 90 天（阿里云 SLS）
- 异常登录告警（异地登录 / 短时多次失败）

## 4. 可观测性

### 日志

| 类型 | 工具 | 保留 |
|------|------|------|
| 应用日志 | Laravel Telescope（开发） / 阿里云 SLS（生产） | 30 天 |
| Nginx 访问日志 | SLS | 30 天 |
| 慢查询日志 | RDS 慢查询 | 永久 |
| 错误日志 | Sentry（推荐） | 90 天 |
| 业务事件 | order_logs / stock_logs / payment_logs（MySQL） | 永久（按月归档） |

### 监控

| 指标 | 工具 | 告警阈值 |
|------|------|---------|
| 系统资源 | 阿里云云监控 | CPU >80% / Mem >85% |
| 接口响应时间 | 阿里云 ARMS | P99 >1s 告警 |
| 错误率 | Sentry | 5xx >1% 告警 |
| MySQL | 阿里云 RDS | 慢查询 >10/min 告警 |
| Redis | 阿里云 Redis | 内存 >80% 告警 |
| 队列堆积 | Horizon Dashboard | 堆积 >1000 告警 |

### 告警通道

- 钉钉群（开发实时）
- 短信（值班人员，深夜紧急）
- 邮件（汇总周报）

## 5. 合规

### 网络安全等级保护

- 第一期：等保 2 级（5 万元起备案）
- 第二期视用户规模评估升 3 级

### ICP 备案

- 必须完成（域名上线前）

### 个人信息保护法（PIPL）

- 隐私政策必须在注册页显示
- 用户可申请删除账号（30 天内）
- 数据出境：第一期数据全部存阿里云国内节点

### 网信办 AI 备案（生成式 AI）

- 第一期 AI 客服调用第三方 LLM（如通义千问），由提供方做安全评估
- 平台需做"使用者实名认证 + 内容审核"（已通过手机号注册满足）
- AI 输出内容标识："本回复由 AI 生成"
