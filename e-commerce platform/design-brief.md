# Design Brief — 中研复材产业互联网平台

> 本文档为设计 Agent 的前置输入，设计工作启动前必须经用户确认。

---

## 1. 风格参考

### 主参考：Airbnb 设计系统（见 DESIGN.md）

沿用 Airbnb 的核心设计语言，但适配 B2B 工业品采购场景：

- **白色画布为底**：`canvas: #ffffff`，大面积留白，信息密度通过卡片组织而非铺满
- **柔和圆角体系**：按钮 8px、卡片 14px、搜索栏 pill-shaped，全局无硬角
- **单一品牌强调色**：替换 Airbnb Rausch 为中研复材品牌色（待确认，建议工业蓝 `#1A5276` 或沿用 `#ff385c`）
- **摄影/产品图驱动**：商品卡片 photo-first，技术参数表退居详情页
- **单层阴影体系**：hover 浮起一层，不做多层级阴影

### 副参考：立创商城（szlcsc.com）

借鉴立创商城的**工业品电商信息架构**，但不照搬其视觉：
- 商品分类导航的层级结构
- 商品详情页的参数表组织方式
- BOM配单的交互流程

### 明确不参考

- 不要传统制造业网站的"蓝+灰+大banner"老旧风格
- 不要信息过载的1688式密集铺货
- 不要暗色/深色主题
- 不要过度拟物、3D、渐变按钮

## 3. 字体方案

Airbnb Cereal VF 为商业授权字体，平台不可直接使用。替代方案：

| 层级 | 字体 | 说明 |
|------|------|------|
| 显示标题 | Inter（display weights 500-700） | Airbnb DESIGN.md 推荐的开源替代，line-height 比 Cereal 略调紧 2% |
| 正文 | Inter 400 | 16px / 1.5 行高 |
| 中文回退 | "PingFang SC", "Microsoft YaHei", "Noto Sans SC" | 平台主要面向国内用户，中文字体优先 |
| 代码/参数 | JetBrains Mono | 规格书参数表、技术规格展示 |

## 4. 目标用户审美定位

**核心用户画像：** 30-45岁男性为主，工业企业采购员或工程师，日常使用阿里巴巴、米思米、立创商城。

**审美偏好：**
- 专业但不死板：信任感 > 花哨
- 高效优先：快速找到型号和价格比视觉冲击更重要
- 参数可读性强：技术规格表要清晰，字号不能太小
- 不排斥现代设计：但对"太设计感"的页面会有距离感

**审美定位总结：** Airbnb 的温暖圆角 + 立创商城的专业信息密度，中间取值。比 Airbnb 信息更密，比立创更干净。

---

## 5. 关键页面视觉密度倾向

| 页面 | 密度 | 说明 |
|------|------|------|
| 首页 | 中等 | 搜索栏突出 + 品类入口卡片（6列）+ 推荐商品（4列），参考 Airbnb 首页的"开放头部 + 密集卡片"节奏 |
| 商品列表 | 偏密 | 左侧筛选栏 + 右侧商品卡片（3-4列），每张卡片：产品图 + 名称 + 型号 + 单价 + 库存状态 |
| 商品详情 | 中等偏密 | 左侧产品图（轮播）+ 右侧参数表 + 价格 + 报价按钮（参考 Airbnb listing detail 的双栏布局，右栏 sticky） |
| AI报价对话 | 偏疏 | 全屏对话窗或右侧抽屉，消息气泡 + 参数卡片 + 报价单卡片，留白多，不压迫 |
| 购物车/结算 | 中等 | 左侧商品清单 + 右侧价格汇总 sticky，参考 Airbnb reservation-card 的组织方式 |
| 后台管理 | 偏密 | 左侧菜单 + 右侧内容区，表格为主，数据密度高但行间距充足 |

## 6. 组件映射（Airbnb → 中研复材）

| Airbnb 组件 | 中研复材对应 | 适配说明 |
|------------|------------|---------|
| search-bar-pill | 全局搜索栏 | 保留 pill-shaped，分段改为：型号/材料类型/规格，右侧搜索按钮改为品牌色 orb |
| property-card | 商品卡片 | photo-first 保留，图片下方改为：商品名 + 型号 + 单价 + 库存标签（绿色有货/红色缺货） |
| reservation-card | 报价/下单侧边栏 | 商品详情页右栏 sticky，展示价格+数量选择+获取报价+加入购物车 |
| guest-favorite-badge | 热销/推荐标签 | 商品卡片左上角浮动标签："热销" / "新品" / "促销" |
| rating-display-card | 不使用 | 工业品场景不需要大字号评分展示 |
| date-picker | 交期选择器 | 保留圆角日期选择交互，用于期望交期选择 |
| amenity-row | 参数规格行 | 图标 + 参数名 + 参数值，保留 12px 行内间距 |
| button-primary | CTA按钮 | 品牌色填充，白色文字，8px圆角，用于"获取报价""立即购买""提交订单" |
| button-secondary | 次级按钮 | 白色填充 + ink 边框，用于"加入购物车""取消" |
| text-input | 表单输入框 | 保留 56px 高度、8px 圆角、focus 态 2px ink 边框 |

## 7. 响应式策略

沿用 Airbnb 断点体系：

| 断点 | 宽度 | 适配说明 |
|------|------|---------|
| Mobile | <744px | 第二期开发，第一期仅PC端，但设计时预留响应式空间 |
| Tablet | 744-1128px | 商品卡片 2 列，筛选栏收起为抽屉 |
| Desktop | 1128-1440px | 主设计尺寸，商品卡片 3-4 列，完整侧边栏 |
| Wide | >1440px | 内容区最大 1280px 居中，两侧留白 |
