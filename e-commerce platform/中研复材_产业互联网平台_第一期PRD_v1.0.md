## 1. 文档说明

### 1.1 编写目的

本文档为中研复材产业互联网平台第一期产品需求文档，明确第一期核心功能范围、业务逻辑、交互规则及验收标准，供研发、设计、测试、运营团队共同对齐使用。

中研复材（深圳）科技有限公司计划搭建一个面向工业品复合材料领域的产业互联网平台，整合电商交易、AI智能体、CRM销售管理、仓储管理四大核心模块，对标海智在线、立创商城、拼客科技、米思米等行业平台。

该平台为2026年全新立项的重点项目，从0到1构建，第一期优先落地电商交易模块与AI智能体模块（自动报价+智能客服），以核心交易链路跑通为目标。

## 2. 用户与角色分析

### 2.1 平台用户类型

本平台为双边平台，服务买家侧和销售侧两类核心用户。

| 用户角色 | 身份描述 | 核心诉求 | 主要使用功能 |
|---------|---------|---------|------------|
| 企业买家 | 工业企业的采购员或工程师 | 快速找到合适规格的复合材料，获取准确报价，高效下单 | 商品搜索、AI报价、下单支付、订单查询 |
| 个人买家 | 小批量采购的个人用户 | 低门槛买到样品或小批量物料，了解产品参数 | 商品浏览、AI咨询、下单 |
| 内部销售 | 中研复材销售团队成员 | 管理客户、跟进订单、查看客户采购历史，支持大客户报价 | 客户管理、订单跟进、手动报价、数据看板 |
| 平台管理员 | 运营和后台管理人员 | 商品上架、订单管理、数据监控、AI维护 | 商品后台、订单后台、AI知识库管理 |

### 2.2 核心用户旅程

**买家旅程**

1. 访问平台 → 搜索/浏览商品
2. 查看商品详情、规格参数
3. 使用AI报价助手输入需求 → 获取自动报价单
4. 确认报价 → 加入购物车 → 提交订单
5. 支付 → 查看订单状态 → 收货确认
6. 售后咨询（AI客服优先，复杂问题转人工）

**销售旅程**

1. 查看新增询价/线索 → 跟进客户
2. 为大客户提供人工报价 → 客户确认下单
3. 跟踪订单履约状态
4. 查看客户采购历史，做复购跟进

## 4. 电商交易模块详细需求

### 4.1 用户注册与认证

**功能说明**

支持手机号注册、企业账号注册两种类型。企业账号需完成企业认证，享受对公转账、账期等企业专属服务。

**功能需求**

- 手机号+验证码注册，支持微信快捷登录
- 企业认证：填写企业名称、统一社会信用代码、上传营业执照，人工审核（T+1工作日）
- 企业认证通过后自动升级企业账号，解锁对公转账支付方式
- 个人/企业账号可随时切换角色视图

**验收标准**

- 手机号注册流程不超过3步，60秒内完成
- 企业认证资料上传成功率>99%，审核通知准时推送

### 4.2 商品中心

#### 4.2.1 商品展示

- 首页：推荐商品、热销品类、活动入口
- 分类页：按材料类型（碳纤维/玻璃纤维/芳纶/其他）、产品形态（板材/管材/型材/织物/预浸料）两级分类
- 搜索：支持型号、规格、材料类型关键词搜索，支持参数筛选（厚度/纤维方向/树脂体系/认证标准）
- 搜索结果支持：综合排序/价格排序/销量排序

#### 4.2.2 商品详情页

- 基本信息：商品名称、型号、主图（多图）、价格（含阶梯价）、库存状态
- 技术规格：材料参数表（密度/拉伸强度/弯曲强度/厚度/纤维方向等），支持下载规格书PDF
- 交期说明：现货标注库存数量，非现货标注预计交期
- 价格说明：小批量单价、阶梯报价（100kg/500kg/1000kg+），大批量需询价
- 商品评价：买家评价展示，支持晒图
- 关联商品：同系列其他规格推荐
- 操作按钮：加入购物车 / 立即购买 / 询价（触发AI报价）

#### 4.2.3 商品后台管理

- 支持单个新建/批量导入（Excel模板）商品
- 商品状态：上架/下架/草稿
- 库存管理：手动调整库存数量，低库存预警（可设阈值）
- 阶梯价设置：按数量区间配置不同单价

### 4.3 购物车与结算

#### 4.3.1 购物车

- 支持多商品加购，展示商品名称/规格/单价/数量/小计
- 数量可修改，支持单个/批量删除
- 实时计算总价（含运费预估）
- 购物车商品失效处理：下架/售罄商品标红提示

#### 4.3.2 结算与下单

- 收货地址：新增/编辑/选择默认地址
- 配送方式：标准物流/加急物流（价格差异展示）
- 发票：增值税专用发票/普通发票，企业账号支持抬头预填
- 订单备注：买家可填写特殊要求
- 价格明细：商品金额 + 运费 + 优惠（如有）= 应付金额

### 4.4 支付

| 支付方式 | 适用对象 | 说明 |
|---------|---------|------|
| 在线支付（微信/支付宝） | 个人/企业 | 即时到账，小额订单推荐 |
| 对公银行转账 | 企业认证用户 | 需上传付款凭证，人工确认后订单生效，大额采购主要方式 |
| 账期支付 | 签署合同的大客户 | 第二期上线，第一期预留入口 |

### 4.5 订单管理（买家侧）

#### 4.5.1 订单状态流转

待付款 → 待发货 → 已发货（物流跟踪）→ 已收货 → 已完成

特殊状态：已取消 / 退款中 / 已退款

#### 4.5.2 买家可操作项

| 订单状态 | 买家可操作 |
|---------|----------|
| 待付款 | 去支付 / 取消订单 |
| 待发货 | 查看订单详情 / 申请取消（审核） |
| 已发货 | 查看物流 / 确认收货 |
| 已完成 | 申请售后 / 评价 |

## 5. AI智能体模块详细需求

### 5.1 模块概述

AI智能体模块包含两个核心能力：AI自动报价引擎和AI智能客服。两者共用底层RAG知识库，通过统一的意图识别层分发用户请求。

### 5.2 整体架构

| 层次 | 说明 |
|------|------|
| 接入层 | PC网页悬浮窗口 / 商品详情页询价按钮 / 移动端（第二期） |
| 意图识别层 | 识别用户意图：报价需求 / 产品咨询 / 订单查询 / 售后处理 / 闲聊 |
| 处理层 | 报价意图→报价引擎；咨询/售后→客服引擎；订单→订单查询接口 |
| 知识层 | RAG知识库（产品规格/价格规则/FAQ/售后政策） |
| 兜底层 | 置信度低于阈值 / 用户主动要求 → 转人工坐席 |

### 5.3 AI自动报价引擎

#### 5.3.1 功能说明

用户通过自然语言或表单输入采购需求，AI自动解析需求参数，匹配产品，生成结构化报价单。解决传统报价依赖销售人工响应、周期长的痛点。

#### 5.3.2 报价触发入口

- 商品详情页 → 「获取报价」按钮
- 首页/全局 → AI助手对话框输入报价需求
- 询价表单：用户填写需求后提交，触发AI报价

#### 5.3.3 报价参数采集

| 参数类型 | 字段 | 采集方式 | 是否必填 |
|---------|------|---------|---------|
| 产品需求 | 材料类型（碳纤维/玻璃纤维等） | AI对话提取 / 下拉选择 | 必填 |
| 产品需求 | 产品形态（板材/管材/织物等） | AI对话提取 / 下拉选择 | 必填 |
| 产品需求 | 规格参数（厚度/尺寸/纤维方向） | AI对话提取 / 文本输入 | 必填 |
| 采购需求 | 采购数量（kg或平方米） | AI对话提取 / 数字输入 | 必填 |
| 采购需求 | 期望交期 | AI对话提取 / 日期选择 | 选填 |
| 采购需求 | 质量要求/认证标准（航空/汽车/民用） | AI对话提取 / 多选 | 选填 |
| 联系信息 | 姓名/公司/手机号 | 用户填写 / 已登录自动带入 | 必填 |

#### 5.3.4 报价逻辑

1. AI解析用户输入，提取结构化参数（若参数不全，主动追问补全）
2. 匹配产品库，找到符合条件的SKU
3. 根据采购数量应用阶梯价规则，计算单价和总价
4. 加入运费预估（根据重量和目的地）
5. 生成结构化报价单，包含：产品名称/规格/单价/数量/总价/有效期/备注
6. 报价单可在线查看，支持下载PDF，支持一键转下单

#### 5.3.5 报价兜底规则

- 以下情况触发人工报价：非标定制品（尺寸/规格超出标准范围）/ 超大批量（>1吨，价格需商议）/ AI匹配置信度<70%
- 转人工时：保留已收集的参数，销售可直接在后台查看并继续报价，无需用户重复填写
- 人工报价完成后通过站内信+短信通知买家

#### 5.3.6 验收指标

| 指标 | 目标值 | 说明 |
|------|-------|------|
| 参数识别准确率 | >90% | AI正确提取采购需求参数的比例 |
| 自动报价完成率 | >60% | 成功生成报价单而无需转人工的比例 |
| 报价响应时间 | <30秒 | 从用户提交到报价单生成的时间 |
| 报价转化率 | >15% | 获取报价后最终下单的比例（持续优化） |

### 5.4 AI智能客服

#### 5.4.1 功能说明

覆盖售前咨询、售中查询、售后处理三个阶段，通过RAG知识库+意图识别提供自动化客服，复杂问题转人工。

#### 5.4.2 支持场景

| 阶段 | 场景 | AI处理方式 |
|------|------|-----------|
| 售前 | 产品参数咨询（什么材料适合航空用途） | RAG匹配知识库回答 |
| 售前 | 价格查询（XX规格多少钱） | 调用报价引擎 |
| 售前 | 交期查询（现货还是备货） | 查询库存接口 + 知识库 |
| 售中 | 订单状态查询 | 查询订单接口，返回状态+物流 |
| 售中 | 修改收货地址 | 已发货前可修改，引导操作步骤 |
| 售后 | 退货申请引导 | 收集退货原因，生成退货工单 |
| 售后 | 发票问题 | 知识库回答常见问题，复杂情况转人工 |
| 通用 | 闲聊/无关问题 | 礼貌拒绝，引导回到业务场景 |

#### 5.4.3 多轮对话设计原则

- 单轮能解决的不做多轮：优先一次性给出完整答案
- 信息不全时主动追问：一次只问一个问题，避免用户填写负担过重
- 上下文保持：同一会话内记住前文提到的订单号、产品信息
- 兜底话术：对任何识别不了的意图，统一回复「我来帮您连接人工客服」

#### 5.4.4 转人工机制

| 触发条件 | 处理方式 |
|---------|---------|
| 用户主动说「转人工」/「找客服」 | 立即转接，保留对话记录 |
| AI置信度低于阈值（连续2轮未能解决） | 主动提示并询问是否转人工 |
| 涉及投诉/纠纷/大额退款 | 强制转人工，不允许AI独立处理 |
| 非工作时间（18:00-9:00） | 告知用户工作时间并留下联系方式，次日跟进 |

#### 5.4.5 验收指标

| 指标 | 目标值 | 说明 |
|------|-------|------|
| 问题解决率 | >65% | AI独立解决而无需转人工的比例 |
| 转人工率 | <35% | 转人工的对话占比（基准值，持续优化） |
| 首次响应时间 | <3秒 | 用户发送消息到AI首次回复的时间 |
| 用户满意度（NPS） | >60分 | 对话结束后用户评分，满分100 |

### 5.5 RAG知识库管理

#### 5.5.1 知识库分类

- 产品知识：各材料类型的技术参数、适用场景、选型指南
- 价格规则：阶梯价规则、大客户折扣规则、运费规则
- 交易政策：退换货政策、发票政策、账期规则
- FAQ：高频问题标准答案库
- 行业知识：复合材料行业术语、认证标准（航空/汽车/民用）

#### 5.5.2 知识库维护机制

- 入库标准：每条知识需有标题、正文、关键词标签、适用场景
- 更新机制：价格/政策变更时，运营人员在后台手动更新，更新后自动触发向量重建
- 质量保障：新内容入库前需人工审核，防止错误信息进入知识库
- Bad Case复盘：每周导出AI未能解决的对话，分析原因，补充知识库或优化提示词
