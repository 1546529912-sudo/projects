# 英语小故事微信小程序 — 开发计划（MVP版）

## 一、项目定位

这是一个面向儿童的英语分级阅读微信小程序。

核心目标：

- 让孩子愿意打开
- 愿意听
- 愿意读
- 愿意点单词
- 愿意持续使用

产品方向：

- 明亮活泼
- 绘本感
- 轻学习感
- 低认知负担
- 手机页面友好

---

# 二、核心功能

## 阅读故事

- 分级阅读
- 英文正文展示
- 适合儿童阅读排版

---

## 整篇朗读

- AI美式童声
- 固定正常语速
- 自动播放整篇故事

> 已确认：
> - 去掉语速按钮
> - 去掉倍速播放

---

## 点击单词

点击单词后：

- 播放美式发音
- 显示音标
- 显示中文意思
- 可加入生词本

展示结构：

```text
apple

/ˈæpəl/

苹果

🔊 播放发音
⭐ 加入生词本
```

---

## 生词本

点击⭐收藏后：

自动进入生词模块。

生词模块显示：

```text
apple

/ˈæpəl/

苹果

🔊 发音
🗑 删除
```

已确认：

- 去掉复习模式
- 去掉翻转卡片
- 去掉拼写测试
- 去掉遗忘曲线

第一版只保留：

- 收藏
- 查看
- 发音
- 删除

---

# 三、难度系统

## 难度等级

共15个等级。

建议命名：

| 等级 | 名称 |
|---|---|
| L1 | Seed |
| L2 | Leaf |
| L3 | Bird |
| L4 | River |
| L5 | Cloud |
| ... | ... |
| L15 | Galaxy |

---

## 第一版内容规模（MVP）

正式规划：

- 保留15级体系
- 每级先做10~20篇故事

不建议第一版直接做：

- 15 × 100 = 1500篇

原因：

第一版重点是验证：

```text
孩子是否喜欢阅读体验
```

后续再通过AI扩充内容。

# 五、关键隐藏模块（必须）

## 1. 内容安全审核模块

AI生成内容必须经过：

```text
AI生成
→ 敏感词检测
→ 年龄内容检测
→ 难度检测
→ 人工抽检
→ 入库
```

目的：

避免出现：

- 不适合儿童内容
- 越级词汇
- 奇怪故事
- 暴力内容

---

## 2. 词汇等级控制模块

这是整个产品真正的技术壁垒。

目的：

控制不同等级只能出现对应难度词汇。

例如：

L1只能出现：

- cat
- dog
- run
- happy

避免AI生成越级单词。

# 九、技术架构建议

推荐：

