# 一、项目定位

这是一个面向儿童的英语分级阅读微信小程序。

核心目标：

- 让孩子愿意打开
- 愿意听
- 愿意读
- 愿意点单词
- 愿意持续使用

产品方向：

- 明亮活泼
- 绘本感
- 轻学习感
- 低认知负担
- 手机页面友好

---

# 二、核心产品理念

这个产品真正的核心竞争力不是 AI，而是：

孩子点击单词那一刻的体验

只要做到：

- 点得准
- 读得快
- 释义准

这个产品就已经成功了一半。

# 十一、后台方案

系统结构：

微信小程序
→ 后端API
→ 数据库
→ 网页管理后台

第一版：

只需要超级管理员。

## 管理后台入口

不单独做网页后台，直接内嵌在小程序内。

进入方式：

去「我的」页面，连点头像5次，进入管理后台。

权限控制：

通过 OPENID 白名单鉴权（云函数 adminStats），非管理员返回 unauthorized。

功能模块：

- 概览：总用户数、今日新增、有阅读/完成记录用户数、近30天各类事件统计
- 故事：按阅读量排序的故事列表，含阅读次数和完成次数
- 事件：最近30条用户行为事件流水
