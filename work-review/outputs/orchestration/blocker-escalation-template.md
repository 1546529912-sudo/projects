# Blocker 升级模板

> 子 Agent 遇到阻塞时填写本模板，提交给主控 Agent

---

## Blocker 报告格式

```markdown
# Blocker: [BLK-XXX]

**提交时间**：YYYY-MM-DD HH:mm  
**提交角色**：[角色名]  
**关联 Task**：[Task ID]  
**返工次数**：第 N 次（第 4 次或连续同类问题 2 次时升级）

---

## 问题描述

[具体描述是什么无法完成，不要只写"出错了"]

## 已尝试的方案

1. 第 1 次尝试：[方案] → 结果：[失败原因]
2. 第 2 次尝试：[方案] → 结果：[失败原因]
3. 第 3 次尝试：[方案] → 结果：[失败原因]

## 根因判断

[我认为根本原因是什么]

## 影响范围

- 直接影响：[当前 Task]
- 间接影响：[哪些后续任务会被阻塞]

## 请主控决策

选项 A：[具体方案，优缺点]  
选项 B：[具体方案，优缺点]  
推荐：[A/B，原因]

---

**主控回复区（由主控填写）**：

处理时间：  
决策：  
定向指令：  
```

---

## 示例 Blocker

```markdown
# Blocker: BLK-001

**提交时间**：2026-05-15 14:30  
**提交角色**：developer  
**关联 Task**：P1-004（healthCheck 云函数）  
**返工次数**：第 4 次

## 问题描述

微信开发者工具可启动，但小程序调用 `healthCheck` 云函数时报 `cloud init failed`，无法完成联通验证。

## 已尝试方案

1. 检查 `app.js` 中 `wx.cloud.init` 配置 → 云环境 ID 为空
2. 补充默认环境 ID → 本地编译通过，但云函数列表仍不可见
3. 重新选择开发者工具绑定环境 → 仍提示无可用云环境

## 根因

当前项目尚未绑定有效的微信云开发环境，导致云函数无法部署和调用。

## 请主控决策

选项 A：由主控协调补齐云环境 ID 和绑定信息（推荐）  
选项 B：暂时将 Phase 1 标记阻塞，等待用户提供云环境配置

**主控回复区**：

处理时间：2026-05-15 15:00  
决策：选项 A，先补齐云环境配置  
定向指令：确认云环境 ID、在微信开发者工具重新绑定后再执行联通测试
```
