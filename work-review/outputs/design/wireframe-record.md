│  │ 今天做了什么？         │  │  文本输入区
│  │                       │  │  最小高度 240rpx
│  │ （灰色占位文字）       │  │  可编辑、可滚动
│  │                       │  │
│  └───────────────────────┘  │
│  [键盘] 切换文字/语音         │  24rpx 灰色小字链接

## 二、AI 整理确认页

### 2-A 结果展示态

```
┌─────────────────────────────┐
│ ← AI 整理确认                 │  导航栏
├─────────────────────────────┤
│  2026年5月16日 的工作记录      │  日期标题 32rpx 粗体
│                             │
│  ┌───────────────────────┐  │
│  │ 📁 产品需求对齐        │  │  项目卡片
│  │ ─────────────────     │  │  白底 圆角12rpx
│  │ ✅ 与产品确认下版本功能列表 │  │  阴影
│  │ ✅ 完成录入页+确认页原型 │  │
│  │                       │  │
│  │ ⚠️ 问题               │  │  可选槽位（有才显示）
│  │ 无                    │  │
│  │                       │  │
│  │ 📅 下一步             │  │
│  │ 出日报结果页原型       │  │
│  │              [编辑] ✎  │  │  卡片右下角编辑入口
│  └───────────────────────┘  │
│                             │
│  [+ 新增项目]                │  次要按钮 灰色边框
│  [↺ 重新 AI 整理]            │  次要按钮 灰色边框
│                             │
│  ┌─────────────────────┐    │
│  │  ✓ 确认，生成日报    │    │  主按钮 #1AAD19
│  └─────────────────────┘    │
└─────────────────────────────┘

交互说明：
- 点卡片"编辑" → 进入 2-B 编辑态
- 多个项目时垂直堆叠多个卡片
- "新增项目" → 插入一张空白项目卡片，进入编辑态
- "重新 AI 整理" → 确认弹窗后重新调用 aiExtract
- "确认，生成日报" → 调用 createReport → 跳转日报结果页
```

### 2-B 编辑态（单个项目卡片内编辑）

```
┌─────────────────────────────┐
│ ← AI 整理确认                 │
├─────────────────────────────┤
│  2026年5月16日 的工作记录      │
│                             │
│  ┌───────────────────────┐  │
│  │ 📁 [产品需求对齐     ] │  │  项目名可编辑（输入框）
│  │ ─────────────────     │  │
│  │ ✅ [与产品确认下版本  ] │  │  任务行可编辑
│  │    [功能列表          ] │  │  
│  │ ✅ [完成录入页+确认页 ] │  │
│  │    [原型图            ] │  │
│  │    [+ 添加任务]         │  │  添加行
│  │    [🗑 删除此任务]       │  │  红色文字
│  │                       │  │
│  │ ⚠️ 问题               │  │
│  │ [无                  ] │  │  可编辑
│  │                       │  │
│  │ 📅 下一步             │  │
│  │ [出日报结果页原型     ] │  │  可编辑
│  │                       │  │
│  │ [🗑 删除此项目]         │  │  红色 底部
│  └───────────────────────┘  │
│                             │
│  ┌─────────────────────┐    │
│  │  ✓ 保存修改          │    │  主按钮 #1AAD19
│  └─────────────────────┘    │
└─────────────────────────────┘

交互说明：
- 所有 [...] 区域均为可编辑 input/textarea
- "添加任务" → 追加一个空白任务行
- "删除此任务" → 移除对应行（剩 1 行时不允许删除）
- "删除此项目" → 弹窗确认后删除整张卡片
- "保存修改" → 退出编辑态，回到 2-A
- 编辑期间不校验内容，确认生成日报时校验必填项
```

- 无错 → 调用 createReport 云函数，跳转日报页
