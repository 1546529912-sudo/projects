# 一、产品定位

# AI 工作记录与智能报告生成工具

用户通过：

- 语音输入
- 文字输入

快速记录当天工作内容。

系统通过 AI 自动：

- 提取工作信息
- 自动拆分项目线
- 自动整理结构化内容
- 自动生成日报
- 后续聚合周报/月报

核心理念：

```text
用户不是在“写日报”，
而是在“自然表达今天做了什么”。
```

---

# 二、MVP 核心目标

## 唯一目标

```text
让用户愿意每天持续记录工作。
```

---

## 核心体验指标

```text
60 秒内完成一次工作记录
```

流程：

```text
语音输入
→ AI 整理
→ 用户简单修改
→ 保存
```

---

# 三、MVP 核心原则

## 3.1 只解决一个问题

```text
日报难写。
```

MVP 阶段不解决：

- AI 人生OS
- 第二大脑
- 团队协作
- 情绪分析
- 教育系统

---

## 3.2 AI 产品核心

真正核心：

| 能力 | 优先级 |
|---|---|
| Prompt 体系 | 极高 |
| Report Schema | 极高 |
| AI Workflow | 极高 |
| AI 稳定性 | 极高 |
| UI 美观 | 中低 |

核心原因：

```text
AI 产品真正的壁垒：
不是页面，
而是 AI 是否稳定、可信、可控。
```

# 十四、MVP 成功标准

满足以下条件：

- 用户愿意每天打开
- 用户觉得记录更轻松
- AI 输出稳定
- 日报可直接复制使用
- 用户修改次数少
- 60 秒内完成记录

---

# 十五、最终产品原则

```text
先解决日报，
再谈 AI 人生OS。
```

避免：

- 产品膨胀
- 一开始做万能系统
- 功能过度复杂

核心目标永远只有：

```text
降低工作记录成本。
```
