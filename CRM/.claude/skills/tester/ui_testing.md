# UI验收方法 — CRM项目

## 适用场景
测试Agent收到开发Agent的 MODULE_COMPLETE 后，对UI进行验收时使用。

---

## 验收原则

1. **对照规范，不凭感觉**：所有判断必须对照 color_system.md 和 component_spec.md，不能主观说"不好看"
2. **具体到像素和色值**：打回必须说"按钮高度应为32px，实际为40px"，不能说"按钮太大了"
3. **功能和UI分开验收**：先验收功能，再验收UI，不混在一起

---

## 验收顺序

1. 功能完整性 → 2. 布局与间距 → 3. 颜色 → 4. 字体 → 5. 交互状态 → 6. 边界场景

---

## 第一项：功能完整性

对照功能清单，逐条验收：

- [ ] 功能清单中该模块的所有功能入口存在（按钮/菜单/链接）
- [ ] 每个功能可以完整执行（新建→保存→出现在列表）
- [ ] 第一版不做的功能确实没有出现

---

## 第二项：布局与间距

### 页面整体布局
- [ ] 侧边导航宽度：220px
- [ ] 顶部导航高度：56px
- [ ] 内容区左右padding：24px
- [ ] 页面最小宽度：1280px，不出现水平滚动条

### 内容区间距
- [ ] 页面标题与内容区间距：24px
- [ ] 卡片/容器内部padding：24px
- [ ] 表单行间距：16px
- [ ] 模块间距：24px

### 表格间距
- [ ] 表格行高（有操作按钮）：48px
- [ ] 表格行高（纯展示）：40px
- [ ] 单元格左右padding：16px

---

## 第三项：颜色验收

验收时对照 color_system.md 中的色值，使用浏览器开发者工具拾色器核对。

### 核心颜色检查
- [ ] 主要按钮背景色：#2563EB
- [ ] 主要按钮文字色：#FFFFFF
- [ ] 页面背景色：#F9FAFB
- [ ] 卡片/弹窗背景：#FFFFFF
- [ ] 正文文字色：#374151
- [ ] 次要文字色：#6B7280
- [ ] 边框颜色：#D1D5DB

### 状态颜色检查
- [ ] 成功状态（绿色）：#16A34A
- [ ] 错误状态（红色）：#DC2626
- [ ] 警告状态（黄色）：#D97706
- [ ] 选中行背景：#DBEAFE

### 禁止项检查
- [ ] 没有出现规范之外的自定义颜色
- [ ] 错误提示不使用红色以外的颜色
- [ ] 成功提示不使用绿色以外的颜色

---

## 第四项：字体验收

- [ ] 页面主标题：24px / font-weight 600
- [ ] 模块标题：20px / font-weight 600
- [ ] 正文/表格内容：14px / font-weight 400
- [ ] 辅助说明文字：12px / font-weight 400
- [ ] 报表核心指标数字：28px / font-weight 700
- [ ] 字体族：system-ui / PingFang SC（中文系统下检查）

---

## 第五项：组件状态验收

### 按钮状态
- [ ] 默认状态：背景 #2563EB，文字白色
- [ ] hover状态：背景加深（可测试：鼠标悬停后颜色变深）
- [ ] disabled状态：opacity 0.4，鼠标 cursor: not-allowed
- [ ] loading状态：按钮内显示spinner，文字或按钮禁用
- [ ] 危险操作按钮（删除）：背景 #DC2626

### 输入框状态
- [ ] 默认状态：border 1px solid #D1D5DB
- [ ] focus状态：border变蓝 #3B82F6，外围出现蓝色光晕
- [ ] error状态：border变红 #DC2626，下方显示红色错误文字

### 表格状态
- [ ] 鼠标悬停行：背景变为 #F3F4F6
- [ ] 选中行（如有）：背景变为 #DBEAFE

### 弹窗
- [ ] 有遮罩层（半透明黑色）
- [ ] 点击遮罩层不会关闭弹窗
- [ ] 关闭按钮在右上角
- [ ] 弹窗内容超出高度时出现内部滚动条

---

## 第六项：边界场景验收

| 场景 | 验收方法 | 期望表现 |
|---|---|---|
| 列表无数据 | 清空数据后刷新页面 | 显示空状态图标+文字"暂无数据" |
| 列表加载中 | 节流网络或大数据量 | 显示骨架屏或loading状态 |
| 客户名称极长 | 输入超过50字符的名称 | 文字截断显示省略号，不撑破布局 |
| 表单必填未填 | 不填必填项直接提交 | 字段下方显示红色错误提示 |
| 弹窗内容过长 | 表单字段超过弹窗高度 | 弹窗内部出现滚动条 |
| 分页最后一页 | 翻到最后一页 | "下一页"按钮禁用 |
| 网络请求失败 | 断网后操作 | 显示错误提示toast |
| 重复快速点击按钮 | 快速双击提交按钮 | 只提交一次，不重复请求 |

---

## 打回格式要求

测试Agent打回时，必须按以下格式填写每个问题：

```
问题编号：UI-001
问题描述：主要按钮背景色不正确
位置：客户管理页 → 新建客户按钮
实际值：按钮背景色为 #1D4ED8
期望值：按钮背景色应为 #2563EB（参见 color_system.md Primary-600）
严重程度：中（视觉不一致，不影响功能）
```

严重程度分级：
- 高：功能无法使用，阻塞主流程
- 中：视觉明显不一致，影响专业性
- 低：细节偏差，不影响使用

---

## 通过标准

以下情况才能输出 TEST_PASS：
- 所有"高"严重程度问题已修复
- "中"严重程度问题已修复
- "低"严重程度问题可由总负责人决定是否放行
