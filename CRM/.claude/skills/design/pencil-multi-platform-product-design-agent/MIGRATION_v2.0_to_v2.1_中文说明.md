## 新模式解决什么问题

v2.0 支持多端页面设计，但 PPT / HTML Deck / 演示文稿不应该被当成普通 Web 页面。

v2.1 将 Deck 作为独立平台模式处理，重点关注：

```text
受众
目标
核心观点
叙事结构
页码节奏
每页 takeaway
视觉系统
投屏可读性
HTML/PPTX/PDF 输出适配
```
