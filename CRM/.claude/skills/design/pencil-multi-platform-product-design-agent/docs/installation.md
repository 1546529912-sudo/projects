# Installation

## Option A — Install as a skill

Copy this repository folder into your agent skills directory. It should contain `SKILL.md` and `references/`.

## Option B — Use project-level instructions

Copy `templates/AGENTS.md` to `AGENTS.md` and `templates/CLAUDE.md` to `CLAUDE.md` in your project root.

## Option C — Single-file mode

Use `standalone/Pencil_MultiPlatform_Product_Design_Agent_SingleFile.md` when your tool does not support skill directories.

## Pencil IDE extension mode

If you use Pencil only through VS Code/Cursor extension, open or create a `.pen` file first, confirm the Pencil editor/canvas is active, and confirm your agent can access Pencil MCP or Pencil extension tools.
