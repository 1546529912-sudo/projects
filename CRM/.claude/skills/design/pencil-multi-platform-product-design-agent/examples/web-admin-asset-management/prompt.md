# Web Admin Asset Management

```text
Use the Pencil multi-platform product design agent skill.

I need you to design a Pencil canvas for an enterprise web admin asset management system.

Scenario:
- Product: facility equipment and fixed asset management platform
- Users: asset administrators, maintenance managers, and department reviewers
- Page: asset list and asset detail workspace
- Goal: help users search assets, compare status, review ownership, inspect maintenance history, and trigger asset actions

Please work in Product Manager + Enterprise Admin / SaaS Dashboard Mode.

Requirements:
- First inspect the current `.pen` file and existing pages, frames, components, styles, and states.
- If any key information is missing, run the Clarification / Intake Gate before drawing.
- Propose 2 design directions before generating the canvas.
- Create an editable Pencil design with clear page structure, dense but readable table layout, filters, status badges, action toolbar, empty/loading/error states, and asset detail side panel or detail page.
- Include realistic sample data for equipment codes, asset names, departments, locations, owners, status, and last maintenance date.
- Verify alignment, spacing, hierarchy, editability, and enterprise admin usability after generation.
```
