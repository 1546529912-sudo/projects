# Smart Building Big Screen

```text
Use the Pencil multi-platform product design agent skill.

I need you to design a Pencil canvas for a smart building operations big screen.

Scenario:
- Product: smart building command center
- Users: operations managers and security staff
- Display: large 16:9 wall screen
- Goal: monitor energy, access control, equipment health, environmental comfort, alarms, and floor-level operation status

Please work in Product Manager + Data Visualization Big Screen Mode.

Requirements:
- Inspect the current `.pen` file first and preserve any existing design system or canvas conventions.
- If key business metrics or display constraints are missing, run the Clarification / Intake Gate.
- Propose a dashboard layout direction before creating the canvas.
- Create an editable Pencil big-screen dashboard with a strong central building/floor status area, surrounding metric panels, chart areas, alarm list, and time/status header.
- Use realistic data labels for energy usage, device uptime, active alarms, occupancy, temperature, humidity, access events, and maintenance tickets.
- Include normal, warning, critical, and data-empty states.
- Verify visual hierarchy, chart readability, screen density, contrast, and editability.
```
