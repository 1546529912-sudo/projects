# Mobile Inspection App

```text
Use the Pencil multi-platform product design agent skill.

I need you to design a Pencil canvas for a mobile inspection app used by field technicians.

Scenario:
- Product: building facility inspection and issue reporting app
- Users: field technicians working on phones during site inspections
- Flow: today's tasks -> inspection checklist -> issue capture -> submit report
- Goal: make the flow fast, clear, and usable while walking through a physical site

Please work in Designer + Mobile App Mode.

Requirements:
- First inspect the current `.pen` file and reuse existing styles or components when available.
- If the request is incomplete, ask only the blocking clarification questions before drawing.
- Propose the mobile information architecture and key screens before generating.
- Create editable Pencil screens for task list, task detail, checklist, photo/issue capture, confirmation, and submitted state.
- Include status, priority, offline sync, progress, validation, empty state, and error state where appropriate.
- Keep the UI touch-friendly, platform-appropriate, and consistent across screens.
- Verify screen flow, spacing, tap targets, text hierarchy, and handoff clarity.
```
