# Contributing

Thank you for considering a contribution.

## Good contributions

- Clearer Pencil MCP rules.
- New platform modes.
- Better examples.
- Real-world case studies.
- Safer `batch_design` patterns.
- Installation docs.
- Translations.

## Please do not submit

- Proprietary system prompts.
- Leaked prompts.
- Private company materials.
- Customer data.
- Unlicensed brand assets.
- Credentials, tokens, or secrets.

## Pull request checklist

- [ ] No proprietary prompts or leaked content included.
- [ ] No private customer/project data included.
- [ ] Markdown renders correctly.
- [ ] Relevant reference files updated.
- [ ] README/docs updated if needed.
