# 配色方法 — CRM项目

## 适用场景
设计Agent为CRM系统制定UI配色规范时使用。

---

## CRM配色原则

1. **专业感优先**：CRM是工具型产品，配色不能花哨，要让用户聚焦数据
2. **信息层次清晰**：通过颜色明确区分主要内容、次要内容、禁用状态
3. **状态语义统一**：成功/警告/错误/信息的颜色全局统一，不同地方不用不同颜色
4. **对比度达标**：文字与背景的对比度 ≥ 4.5:1（WCAG AA标准）

---

## 色彩系统结构

### 一、品牌色（Primary）
系统主色调，用于主要操作按钮、选中状态、链接、强调。

```
Primary-600（主色）：  #2563EB   用于主要按钮背景、激活Tab
Primary-500（悬停）：  #3B82F6   用于按钮hover状态
Primary-100（浅色）：  #DBEAFE   用于选中行背景、标签底色
Primary-50（极浅）：   #EFF6FF   用于大面积背景强调区域
```

### 二、中性色（Neutral / Gray）
用于文字、边框、背景、分割线。

```
Gray-900：  #111827   主标题、重要数据
Gray-700：  #374151   正文、表格内容
Gray-500：  #6B7280   次要文字、占位符
Gray-300：  #D1D5DB   边框、分割线
Gray-100：  #F3F4F6   表格斑马纹、悬停行背景
Gray-50：   #F9FAFB   页面背景、侧边栏背景
White：     #FFFFFF   卡片背景、弹窗背景
```

### 三、语义色（Semantic）
固定含义，全局一致，不能随意挪用。

```
成功 Success：
  主色   #16A34A   合同签订、跟进完成、测试通过
  浅色   #DCFCE7   成功状态背景

警告 Warning：
  主色   #D97706   即将到期、待处理提醒
  浅色   #FEF3C7   警告状态背景

错误 Error：
  主色   #DC2626   操作失败、必填未填、逾期
  浅色   #FEE2E2   错误状态背景

信息 Info：
  主色   #0891B2   一般提示、说明文字
  浅色   #CFFAFE   信息状态背景
```

### 四、商机阶段色（Pipeline Stage）
销售漏斗中各阶段的专属颜色，不与语义色混用。

```
初步接触：  #8B5CF6   紫色
需求确认：  #F59E0B   橙黄
方案报价：  #3B82F6   蓝色
谈判中：    #F97316   橙色
已成交：    #16A34A   绿色
已失单：    #6B7280   灰色
```

## 颜色使用规则

### 按钮颜色规则
| 按钮类型 | 背景 | 文字 | 边框 |
|---|---|---|---|
| 主要操作（新建、保存） | Primary-600 | White | 无 |
| 次要操作（取消、返回） | White | Gray-700 | Gray-300 |
| 危险操作（删除） | Error主色 | White | 无 |
| 禁用状态 | Gray-100 | Gray-400 | 无 |

### 表格颜色规则
- 表头背景：Gray-50
- 普通行背景：White
- 悬停行背景：Gray-100
- 选中行背景：Primary-100
- 边框：Gray-200

### 标签/Badge颜色规则
- 使用语义色的浅色做背景，主色做文字
- 禁止用超过5种不同颜色的标签同时出现在一个页面

---

## 禁止事项

- 禁止在同一模块内使用超过3种颜色
- 禁止用红色以外的颜色表示错误
- 禁止用绿色以外的颜色表示成功
- 禁止直接使用CSS颜色名（red、blue），必须用色值
- 禁止自己发明新颜色，所有颜色必须从此规范中取用

---

## 暗色模式（Dark Mode）
当前版本不做暗色模式，所有颜色基于浅色背景设计。

---

## 交付物要求
设计Agent输出配色规范时，必须包含：
- [ ] 所有色值（十六进制）
- [ ] 每个颜色的使用场景说明
- [ ] 对比度验证（至少主要文字颜色组合）
- [ ] CSS变量定义清单（供开发Agent使用）
